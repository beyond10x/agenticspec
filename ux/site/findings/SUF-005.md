main content" moves focus to the article, and then Tab walks every link in it (dependencies, used
by, every relation of every entity, the KPI catalogue link) before the first entry of "On this
page". On harness that is about 60 Tab presses for one jump. A pointer user reaches the same entry
in one click (screen_only.actions counts 1). Sessions: find-harness-kpis, toolcall-lifecycle,
what-question-depends-on.

focus order.
