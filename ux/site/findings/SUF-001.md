evidence_lines: website/src/components/blocks/ArchitectureFrame.tsx, `src` is `/architectures/<name>.html?theme=…` (from the generated pages, crates/agenticspec-docs)
regression_asset: website/e2e/pages.spec.ts#page /docs/architectures/<name> (frames.ts: "lands on", "shows … not the <name> architecture"), under docusaurus serve; website/e2e/findings.spec.ts#SUF-001 every architecture frame shows its architecture on a host with the layout of GitHub Pages (e2e/pages-host.ts)

Every architecture page embeds `/agenticspec/architectures/<name>.html?theme=<mode>`. `docusaurus
serve` (the server of the gates, and of the preview on port 8471) answers that path with
`301 Location: /architectures/<name>`: the redirect drops the base path `/agenticspec/`, and the
frame then draws the landing page of the site (hero "…actually went.", the "How it works" strip)
inside the docs page, at full height. The caption above it still names the architecture and the
"Open full screen" link has the same URL, so it lands on the same wrong page. Seen on all 5
architecture pages in both themes, at 1440x900: the frame check of the sweep and of
`pages.spec.ts` runs at that size only, and the task runs at other widths do not check the frame
(corrected after the S-01 report review, which had "every viewport"). The frame is the subject of
the page: without it the reader has only the tables below.

Not checked in S-01: GitHub Pages serves `<name>.html` without a redirect, so the published site
may have shown the frame correctly; the gate runs on `docusaurus serve`, as the preview does.

Fix (S-01 change set): the generator (crates/agenticspec-docs/src/arch.rs) points the frame and
its link at `/architectures/<name>`, without `.html`. `docusaurus serve` answers it with 200 from
the docs-system's trailing-slash copy `architectures/<name>/index.html`, which does not redirect
a path without a slash; GitHub Pages answers it from `architectures/<name>.html`, the order the
docs-system's copies assume for every docs page. Red before the fix: the five frame tests of
`pages.spec.ts` (lands on /agenticspec/, shows the landing page); green after it on all 10
architecture pages. The GitHub Pages test passes before and after: it guards the published layout.
