Lift agent sessions into one IR and evaluate KPIs over them

Usage: agenticspec [OPTIONS] <COMMAND>

Commands:
  analyze      Find the Claude Code sessions on this machine, evaluate each, and write a dashboard file
  export       Export a procedure as a canon protocol and loom bindings
  kpi          Evaluate the KPIs over every Claude Code session in a time window
  lift         Lift one Claude Code session and its sub-agents into session IR commands and replay them
  mine         Find runs of tool calls that recur in agent turns across sessions
  procedure    Lift a mined pattern into a procedure over its matches
  query        Run an sq module of rules, queries and checks over one session or the sessions of a window
  serve        Serve the UI and its views from the local store on 127.0.0.1, synced every 5 seconds
  sim          
  sync         Lift the new and changed sessions of a window into the local store
  ui           
  completions  Emit shell completions
  help         Print this message or the help of the given subcommand(s)

Options:
      --config <global_config>
          

      --state-dir <global_state>
          

      --output <global_output>
          [default: human]
          [possible values: human, json]

  -h, --help
          Print help
