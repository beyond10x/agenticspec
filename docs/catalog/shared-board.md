## Run it

Put the downloaded files in one directory and run the experiment with `agenticspec sim`. `agenticspec` is the binary of every [release](https://github.com/beyond10x/agenticspec/releases); a checkout of the [repository](https://github.com/beyond10x/agenticspec) builds it with `cargo build --release -p agenticspec`. The same seeds give the same `result.json`.

```sh
agenticspec sim run shared-board-tuning.yaml --out out/
```

`agenticspec sim check shared-board.best.yaml` accepts the optimized architecture. To search on from it, set `architecture: shared-board.best.yaml` in the experiment; its fitness as written is then the best fitness above.

In a checkout, the same run is `agenticspec sim run experiments/shared-board-tuning.yaml --out out/`.

With `--events`, the run also writes `out/events.jsonl`: the run of the result's timeline as an event log, one line per building-block event (`agentic.work.TaskCreated`, `agentic.resource.ClaimQueued`, ...) with its sequence number, time, part, copy and subject key (`task-3`). The same seed writes the same lines, and `result.json` does not change.
