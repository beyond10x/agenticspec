## Run it

Put the downloaded files in one directory and run the experiment with `agenticspec sim`. `agenticspec` is the binary of every [release](https://github.com/beyond10x/agenticspec/releases); a checkout of the [repository](https://github.com/beyond10x/agenticspec) builds it with `cargo build --release -p agenticspec`. The same seeds give the same `result.json`.

```sh
agenticspec sim run scheduled-loops-tuning.yaml --out out/
```

`agenticspec sim check scheduled-loops.best.yaml` accepts the optimized architecture. To search on from it, set `architecture: scheduled-loops.best.yaml` in the experiment; its fitness as written is then the best fitness above.

In a checkout, the same run is `agenticspec sim run experiments/scheduled-loops-tuning.yaml --out out/`.
